# 603web

603寝室主题的静态互动网站，包含寝室概况、论坛、小卖部和查寝通报四个页面。

## 本地预览

项目不需要安装依赖或构建。在仓库根目录启动一个本地静态服务器：

```sh
python3 -m http.server 8000
```

然后在浏览器打开`http://localhost:8000/`。也可以直接打开[`index.html`](index.html)，但建议通过本地服务器预览，以便使用与静态托管接近的资源路径。

## 页面与交互

- **寝室概况：**展示首页视觉、室友资料和轮播标语。
- **寝室论坛：**查看预置帖子、发布帖子和回复。发布帖子消耗注意力点数。
- **603小卖部：**领取每日生活费，使用603币购买页面中的物品，并受限购数量约束。
- **查寝通报：**提交线索、查看档案与日志，推进解密进度。达到100%后可查看完整关系网。

上述点数、货币、帖子、购买记录和解密进度都在浏览器本地模拟。页面没有账户系统或后端接口；刷新后状态由浏览器的`localStorage`恢复。页脚的重置按钮会清除该浏览器保存的进度。

## 项目结构

```text
.
├── index.html             # 页面结构与交互脚本
├── css/
│   ├── style.css          # 基础视觉和响应式布局
│   └── interactions.css   # 交互状态与界面细节
└── assets/                # 页面图片资源
```

修改文字或交互时编辑[`index.html`](index.html)；调整布局与配色时编辑[`css/style.css`](css/style.css)和[`css/interactions.css`](css/interactions.css)。图片文件位于[`assets/`](assets/)。
