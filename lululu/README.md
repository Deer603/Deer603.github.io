# 加密鹿 🦌

一个把文字藏进“鹿群密文”的纯前端小工具。

输入文字和可选密钥后，工具会把内容编码成由鹿、森林和夜空主题符号组成的密文；使用相同密钥即可将密文还原。

## 功能

- 使用鹿群主题符号生成密文
- 支持自定义密钥，也支持留空使用空密钥
- 支持加密、解密、智能转换、交换、清空和复制结果
- 浏览器端直接运行，无需后端服务
- 支持复制时带入的空格和换行，解密时会自动过滤

## 使用

1. 在“密钥”输入框中填写密钥，可留空。
2. 在“原文/密文”区域输入要加密的文字。
3. 点击“鹿加密 🦌”。
4. 需要解密时，粘贴鹿群密文并输入完全相同的密钥，点击“鹿出来 🌿”。

也可以使用“智能转换”，让工具根据输入内容尝试判断应该执行加密还是解密。

## 本地运行

这是一个不依赖构建工具的静态网页，直接用浏览器打开 `index.html` 即可使用。

如果希望通过本地HTTP服务访问，可以在项目根目录运行：

```bash
python3 -m http.server
```

然后打开 <http://localhost:8000>。

## 原理与限制

文字会先转换为UTF-8字节，再通过基于密钥生成的替换表映射到主题符号，并插入填充符号，让结果看起来像一串鹿群密文。

这是一个有趣的前端编码工具，不应替代经过专业审计的加密软件。不要用它保护密码、私钥、财务信息或其他高敏感数据；密钥也不会被上传到服务器，但在浏览器页面中输入的内容仍应遵循你对本地环境的安全要求。
