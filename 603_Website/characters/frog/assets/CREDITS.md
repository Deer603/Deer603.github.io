# 素材来源

## 纸张音效

- `paper-gather.mp3`：Julie Damsgaard / Spring Spring / Spring Enterprises 的真实纸张录音。
  来源：[Opening and Closing a Map Sounds](https://opengameart.org/content/opening-and-closing-a-map-sounds)。
  原文件 `snd_use_map.wav`，作者说明为亲自录制地图展开、合拢的声音；许可为 CC0 1.0。
  本站截取 0.32–0.80 秒，转为 44.1 kHz 单声道 MP3，降低音量并在首尾淡入淡出。
- `page-turn.mp3`：yd 的翻页声。
  来源：[Old Pages/Flip with sound](https://opengameart.org/content/old-pagesflip-with-sound)。
  原文件 `FlippingPages_0.ogg`；许可为 CC0 1.0，转为 44.1 kHz 单声道 MP3。
