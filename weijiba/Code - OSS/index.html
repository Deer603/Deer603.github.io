阅读重点许可、上游与定制

Code - OSS在KunCode词条里承担“上游基础”的位置。KunCode README 表述为基于 Code - OSS 定制，这意味着项目保留了熟悉的编辑器工作流，同时加入自己的品牌、产品配置、中文界面与603相关体验。

“基于”不是“等同”。KunCode是独立项目，具体改动、发行方式、内置资源和维护责任要看 KunCode 自己的仓库；上游许可、版权和第三方组件说明则需要按照对应项目与仓库文件分别阅读。

上游与定制

上游项目提供可复用的编辑器基础，KunCode在其上叠加产品名称、图标、主题、助手和平台发布流程。这种关系让它既能借用成熟工作流，又必须承担自己的打包、维护和资料说明责任。

许可阅读

KunCode README 与仓库许可证信息采用 MIT License 表述，同时保留上游 Code - OSS 的版权和许可声明。使用或再分发时，不能只看一个许可证标题而忽略第三方组件。

品牌边界

KunCode公开声明与 Microsoft Corporation 没有隶属、授权、赞助或官方合作关系；本页因此把上游技术基础和商业品牌身份分开记录。

上游不是亲戚称呼

Code - OSS是KunCode资料里能查到的上游基础，不是一个可随意互换的商标。说清改了什么，比把两个名字排成亲属关系图更有用。
