DeerPhotos (Chinese: 鹿图, Lutu) is a generative AI image skill maintained by Roylyl for creating Deer Group portraits and scenes. It maps names and aliases to recurring characters and passes the reference images and composition instructions to the host's image-generation tool.[1]

Character references and image generation

The project supplies standard portraits, full-body views from multiple angles and character notes. Given a cast and scene, the skill selects reference files for the host tool to use. Follow-up instructions can retain the same cast while changing the setting, clothing, poses or composition.[1]

Each generated scene has a record listing its cast, reference files, prompt and skill version.[1]

Version history and group announcements

The documentation for 3.0.0 lists 11 characters and 83 aliases. It also records the addition of Dai'er, a white goose.[1][2]

At 18:07 on 27 October 2026, Roylyl shared the repository link in the Deer Group. A link to the 3.0.0 release page appeared at 19:02 that day.[3]
