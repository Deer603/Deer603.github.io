Deer Test
Deer Group web project
Website nameYou're a Deer
Shared in the group16 October 2026

Deer Test is the Deer Group's name for the similarity ranking on the You're a Deer website. The page accepts photos or camera input and states that images are processed on the user's device.[1][2]

Photo and camera matching

The website compares a face in an input image with a set of reference photographs. Two models, face-api and SFace, score each match. The page averages their scores and ranks the results by overall similarity. The percentage indicates the degree of resemblance to the reference photo. When using the camera, the program combines successive frames and starts showing rankings after collecting at least three.[3]

Sharing in the group

At 10:27 on 16 October 2026, Roylyl posted the address of the You're a Deer website. Thirteen seconds later, he added, “Take the Deer Test first.”[1]
