KunCode
Integrated development environment
Maintainer603
Upstream projectCode - OSS
Operating systemsWindows、macOS
LicenseMIT

KunCode is an open-source integrated development environment maintained by 603 and based on Code - OSS. It supports code editing, project management, a terminal, debugging and extension management. Its built-in Kunkun AI assistant draws on a local text corpus.[1][2]

Versions and platforms

Project information dated 4 September 2026 lists two installers for version 1.0.0, one for Windows x64 and one for Macs with Apple silicon. Version 2.0.0, released on 3 October 2026, added a macOS x64 installer for Intel processors alongside the Windows x64 and macOS arm64 installers.[2][3]

Extensions and assistant

KunCode uses Open VSX as its extension registry. Project documentation describes Kunkun AI as an assistant that matches situations against a local text corpus and can respond offline.[1][2]

Product website

The KunCode website introduces the software through a simulated editor. Readers can switch among installation errors, choosing a paper topic and group collaboration to explore sample Kunkun AI conversations and exercises. Downloads are organized by operating system, with separate Mac installers for Apple silicon and Intel processors.[6]

Public coverage and links shared in the group

The 603 Vision WeChat account pinned an article about the release of KunCode for macOS. A link to the project page appeared in the Deer Group on 12 October 2026.[4][5]
