# XWCRecognizer

在浏览器中调用摄像头，使用face-api和SFace两个识别模型，对照13位预设人物、76张参考样本进行多帧比较，显示人物与综合匹配度排行。也可以通过“对比照片”处理静态照片。网页采用浅灰背景、圆角预览区域和简洁按钮，模型加载进度在预览框中央显示。

## 快速开始

准备Node.js18或更高版本，然后在XWCRecognizer目录运行：

```powershell
node serve.mjs
```

在浏览器打开[http://localhost:8765](http://localhost:8765)。服务器只绑定127.0.0.1，供当前电脑访问，不需要安装依赖。需要更换端口时可运行：

```powershell
node serve.mjs 8766
```

1. 打开页面，在预览框中央查看模型加载进度。加载完成后，右上角显示“已就绪”。
2. 启动摄像头并允许浏览器访问，页面会持续检测画面中的人脸，更新人物排名与匹配度。
3. 也可以选择“对比照片”，从电脑选取一张照片，查看其中每张人脸的匹配结果。
4. 实时画面首次采集满3帧后显示排行，随后持续汇总最近5帧。

## 主要功能

- 打开网页自动加载固定的13位预设人物与76张参考样本，每人最多支持16张。
- 支持实时摄像头匹配，在人脸框与人物列表中显示匹配度。
- “对比照片”支持单张照片中的多张人脸。
- face-api与SFace分别计算特征与分数，再汇总为综合匹配度；内部保留两个模型各自的第一名与一致性结果。
- 摄像头对最近5帧的每个人物评分取平均后排名，首次采集满3帧显示结果。前两名分差不作为排除第一名的条件。
- 用户界面只展示人物与综合百分比，不展示模型名称、分差、帧数或调试说明。
- 模型加载阶段在预览框内显示大号百分比和进度条，完成前禁止启动摄像头或对比照片。下载失败可在原处重试。
- 脚本、模型与预设样本随项目本地提供，人脸处理在浏览器中完成。

20261014-named-folders批次使用用户按姓名分文件夹整理的35张截图，去除相册工具栏和底部缩略图，已导入35张主图参考样本，新增邓宇航、唐博釜、涂腾辉，现有13人、76张参考样本。全部35张已导入。人物标签来自用户文件夹名，不通过相貌重新分配姓名。

这里的“训练资料”用于准备比对样本、扩充参考库，匹配过程使用现有开源模型提取特征，不从头训练人脸识别模型。样本录入成功不等于已证实识别准确率提高。

- presets/library.json：已计算的人脸特征、人物信息和缩略图，供网页打开时直接加载。
- presets/sface-library.json：同一组13人、76张参考样本的SFace特征，沿用现有人物标签。
- presets/images/：从训练资料裁切的人脸样本图片。
- presets/source.json：人物姓名与样本路径，用于记录预设样本来源。

网页对照这些固定样本进行匹配，摄像头画面与选取的对比照片不会自动变成新的人物或训练样本。

## 综合匹配度

每个识别模型各自选择该人物最接近的两张参考图。face-api取平均欧氏距离d，SFace取平均余弦相似度c；只有一张参考图的人物使用现有单样本展示排行。

```text
face-api分数=clamp(1-d/1.2,0,1)×100
SFace分数=clamp(c,0,1)×100
综合匹配度=(face-api分数+SFace分数)/2
```

摄像头按人脸框位置关联连续画面，对最近5帧的两套分数分别取平均，再计算综合排名；首次采集满3帧开始显示。人脸离开画面或过小时重新采集。分析画面最长边为960像素，人脸框短边至少80像素。静态照片只计算一次，不以重复计算模拟多帧。

两个识别网络独立提取特征，共用SSD检测与68点关键点定位。SFace使用眼睛中心、鼻尖和嘴角构成的5点进行112×112对齐。内部以两个模型的第一名是否相同、各自双样本支持是否达到阈值记录一致性；face-api阈值65分，SFace余弦阈值0.363。综合排名持续展示，不因模型分歧或分差小而隐藏第一名，界面不将排名宣称为身份确认。

综合百分比是两套相似度分数的等权平均，没有经过概率校准，不代表身份正确率。两个模型可能同时出错，共用的检测与关键点误差也可能影响两者。

下载进度按模型文件收到的字节数映射到0%～85%，随后进入初始化和资料读取阶段，全部准备完成后才显示100%。模型、运行库和参考资料均从本站读取，不依赖第三方CDN。

本项目没有活体检测功能，照片或屏幕中的人脸也可能被检测和匹配，不适合直接作为门禁、支付或其他身份认证依据。

## 数据处理

摄像头画面与新选取的对比照片均在浏览器中处理，不会上传到服务器。预设人物信息、人脸特征和裁切样本保存在项目静态文件中，网页会读取这些文件进行比对。

如果将整个项目发布到公开网站，预设人物信息、人脸特征和样本图片也会随静态文件公开。需要限制访问时，请将项目放在本地或有访问控制的环境中。

## 运行要求

- 使用Chrome、Edge等支持摄像头、WebGL和WebAssembly SIMD的现代浏览器。
- 摄像头要求HTTPS或localhost等安全上下文；请通过本地服务器或HTTPS站点打开页面。
- 实时匹配需要可用摄像头，并授予当前站点摄像头权限；“对比照片”可直接使用本地图片。
- 保留vendor、models与presets目录，页面通过相对路径加载本地脚本、模型和预设人物库。

如要放在静态网站上，上传整个XWCRecognizer目录即可，并按需要限制预设资料的访问权限。Node.js仅用于本地静态服务器；网站本身不需要人脸识别后端。

## 开源依赖

本项目使用[@vladmandic/face-api](https://github.com/vladmandic/face-api)的1.7.15版本，加载SSD Mobilenet V1人脸检测、68点人脸关键点与128维人脸识别三个模型。该上游仓库已于2025年2月5日归档，使用此固定版本时需自行留意后续浏览器兼容性。

第二个识别模型采用[OpenCV Zoo的SFace](https://github.com/opencv/opencv_zoo/tree/main/models/face_recognition_sface)，模型文件为face_recognition_sface_2021dec.onnx，使用[ONNX Runtime Web](https://onnxruntime.ai/docs/get-started/with-javascript/web.html)1.30.0在浏览器中推理。SFace模型约38.7MB，WebAssembly运行文件约14.2MB，首次加载需要下载这些文件。
